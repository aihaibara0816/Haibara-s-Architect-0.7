# 0.7 当前能力补充

当前新增能力以 [配方与 CLI](quickstart.md)、[六领域规则](skills07.md) 和 [完整流程](workflow.md) 为准。新增六配方与 Room06，不把 56 个归档条目计为 56 个通用生成器。以下保留 0.6 时点的能力说明。


# 能力与状态

| 能力 | 当前状态 | 实际消费者与边界 |
|---|---|---|
| 现实建筑资料研究 | 工作流已整理 | 人/模型阅读证据并形成构件判断；没有通用自动分割或相机恢复 |
| 可选三维模型归一化 | 历史工具 | `ha03/architect/`；原始模型读取有可选依赖，不在新0.6验证范围 |
| 证据冲突和参数变更检查 | 可执行 | `hafusion/evidence.py`；不能替代证据本身的真实性判断 |
| 建筑空间交接 | 可执行规划 | `design_handoff.py`；单位、用途、楼层、模块、通道与照明任务 |
| 确定性随机选择 | 0.6 可执行规划 | `variation06.py`；独立通道、稳定ID、冻结、边界/keepout；未自动消费为全部几何 |
| 不覆盖运行记录/父链校验 | 0.6 可执行 | `workflow06.py`；一致性检测，不是来源签名 |
| 模型提案/工具调用 | 0.6 可执行 | 受限分发器；宿主自己接模型、控制预算与重试 |
| 建筑 NBT 生成 | 11 个专用入口 | 注册案例；新建筑须增加适配器，不能从任意图片直接构建 |
| 窗、家具、灯、古典细部 | 共享函数 + 案例实现 | 支持有限方块与明确构造；不等于完整室内生成器 |
| 12 用途/6 园林/18 研究模块 | 设计目录 | 数量不等于可执行生成器数量 |
| 随机开窗/材质研究 | 实验规划器 | `experiments/concept/`；见固定窗口等已知缺陷 |
| 最终 NBT 回读 | 可执行 | 文件读回与采样契约；未声明的样本不自动通过 |
| 离线视图/光场 | 历史专用工具 | 渲染环境可能不同；元数据不等于已生成图像 |
| 碰撞、导航、真实照明 | 待游戏验证 | 不把离线几何或材质色彩解释为游戏物理效果 |
| 铁路三角结构/坡地城市规划 | 概念与专题研究 | 尚无本仓库通用地形—路网—铁路—建筑联合求解器 |
| 通用自动 Agent | 未完成 | 有可接入组件，缺端到端建造、视觉评价和重试闭环 |

版本也分层：仓库发行 `0.6.0`，新工作流 `0.6.0`，旧几何内核 `0.4.0`，空间交接 schema `0.4`。原建筑 manifest 使用生成当时的版本，不追溯替换。
