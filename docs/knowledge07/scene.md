# 场景、街区与地形

适用：乡村、骑楼、日式/大正街区、滨水城市和铁路周边场景。这是仓库可复用工作规则；个人技能安装状态见主 README。

## 输入

- 原地形或明确标注的自建高度场
- 水系、山脊、岸线、铁路和固定地标
- 功能节点、道路骨架与入户关系

## 执行规则

1. 先保护地形、水系和既有对象，再组织道路与地块。
2. 主路、支路、入口有实际连接；技术可达不代替完整路幅与眼高辨识。
3. 以用途、形体、朝向、分段标高和院界产生变化；不能只抖动矩形网格。
4. 公共建筑配置到达、停留、坐席与照明；村镇屋脚、店前、后勤分别处理铺地。
5. 广州塔和松山湖固定；海湾不填、西河保留、铁路边坡与隧道约束优先，未接入地形测量的城市图保持概念状态。
