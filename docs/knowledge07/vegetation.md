# 树木、植物、园林与装饰

适用：林地、林缘、树冠层次、室内盆器、花箱、庭院与生活小物。这是仓库可复用工作规则；个人技能安装状态见主 README。

## 输入

- 候选位置、用途和环境
- 完整树冠/叶冠包围范围
- 根部或盆底承托、通路和窗景禁放区
- 独立seed、稳定group_id与component_id

## 执行规则

1. 按林地—林缘—聚落形成疏密和层次，不在整片地面等距撒树。
2. 容器、株形、支撑和背景分别设计；主景、高低呼应与留白同时存在。
3. 先冻结地形、功能、门窗、灯与主家具，再在合法候选内变化种类、树冠、朝向和相对高度。
4. 每个构件和随机通道独立寻址；换一组或新增一组不重抽其他已认可对象。
5. 按完整叶冠与支撑检验；没有合法位置则拒绝/跳过并说明，不挤窄通道。
6. 草、藤和旧化按环境与维护状态组织；不要每格独立抽材质。
