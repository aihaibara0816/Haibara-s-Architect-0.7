# Haibara’s Architect 完整编排

适用：从需求到研究、建造、验收、归档与规则升级。这是仓库可复用工作规则；个人技能安装状态见主 README。

## 输入

- 需求与授权范围
- 事实/原创/局部返工路线
- 源案例与当前验收状态

## 执行规则

1. 先归档证据，再抽象规则，最后接入具体消费者和回归例；不因写了规则就宣布生成器已实现。
2. 模型只提交结构化数据；路径、可运行适配器和权限由宿主决定。
3. run不可覆盖；失败保留，修订新建；哈希只证明内部一致，不证明源身份或审美质量。
4. 案例学习、构件配方、确定性规则与回归测试不是神经网络权重训练。
5. 使用前读取CLI能力表，研究、规划、已生成、实机、用户认可分别记录。

案例：`reading-garden`、`industrial-yard`、`room06`。
