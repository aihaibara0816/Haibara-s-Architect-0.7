# 现实建筑与特色建筑

适用：新建筑复原、特色建筑研究、形体与立面返工。这是仓库可复用工作规则；个人技能安装状态见主 README。

## 输入

- 建筑身份、年代与范围
- 逐构件图片/模型证据
- 尺度和坐标、固定构件

## 执行规则

1. 按构件拆轮廓、空气层、外壳、内部层与接口；证据与推断分列。
2. 图片和模型分别确认单位、方向、缺件；以构件取舍，不能整体平均融合。
3. 四向同框45度与垂直正交俯视绑定最终NBT哈希。
4. 新增案例必须有参数消费者；现有单案例网格代码不是通用高保真引擎。

## 消费入口

- `tools/haf.py build-case`
- `tools/agent.py`
- `hafusion/review.py`

## 案例与验收

案例：`canton`、`pazhou`、`guangzhou_customs`、`guangzhou_south`。

- 主体宽深/收分/悬挑比例
- 完整承托、门洞地坪、两格净空、屋面拼接
- 灯光保持与伪内饰范围
- 最终NBT回读与分项反馈
