# 完整内饰、家具与生活组景

适用：空壳填充、功能室内、家具精细化、门框修复、软装与照明。这是仓库可复用工作规则；个人技能安装状态见主 README。

## 输入

- 完整墙地顶与净高
- 主用途、活动顺序、容量与公私分区
- 门窗、楼梯、工作面和固定家具

## 执行规则

1. 先解释每个区域的用途，留白必须有理由；不以物件数量或填充率验收。
2. 家具拆主体、承托、靠背/扶手、框边、台面与使用侧，再组合成床头、厨房、吧台、阅读等活动组。
3. 现代两层楼板/天花，光源嵌入；中世纪一层构造和有承托的灯笼分别处理。
4. 1–9层功能房间、走道、楼梯和公共区全部有照明；不随机熄灭半数房间。
5. 植物、帘、地毯和局部灯与家具同步设计；固定门窗和主要家具不参与装饰散点随机。
6. 门扇、框、门楣、上下半扇、铰链、床头脚和方块实体必须在最终NBT检查。
