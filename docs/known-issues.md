# 已知问题与未完成项

1. **新工作流不产出 NBT。** 它检查并保存设计计划与提案；计划尚未接上任意建筑几何消费者。实际建造仍走注册案例适配器。
2. **不是完整自主 Agent。** 未实现模型网络请求、自动搜索、预算管理、多轮重试或游戏操作。模型工具 schema 与宿主分发器已提供。
3. **资料包不是所有历史原包。** 本仓库只选择有用源码、参数、成果与失败证据。广州塔 V6 r02 最终 NBT 尚未补入；0.5 独立分支目前有索引和问题摘要，未把未获取的源码写成可下载文件。
4. **公开精选包不适用旧全包哈希验收。** `validate_release_04.py` 等针对原始完整档案；读取它们理解历史，不用来给本发行强行盖通过章。
5. **旧版随机开窗存在固定范围问题。** 窄 fixed 组仍可能被最小宽度规则扩大；它未接入默认新工作流。植物密度参数是组级概率，不是精确数量配额。
6. **内饰实验依赖不完整。** 固定四房实验缺少原分支 `rural_states` 和专用渲染资产；部分家具状态超出旧注册词表。这里整理经验，没有宣称已经修复并重建所有旧作品。
7. **图像/游戏验收不完整。** 许多旧 run 只有相机/报告元数据；不能把它当作图像存在或用户验收。离线照明、原版方块支持和游戏碰撞分别验证。
8. **旧内核的覆盖范围有限。** 稳定随机未统一改写所有历史建造循环，冻结规则也不自动应用到每个旧脚本。使用前阅读该案例消费者。
9. **依赖测试限制。** 当前运行环境缺 `jsonschema`，完整旧套件中一项因此未运行完成；声明的 pip 依赖包含它。最新具体结果见 [验证记录](validation.md)。

概念实验的源码级反例和依赖细节见 [概念已知问题](known-issues-concept.md)。历史错误保留用于教学；修订时新增版本，不覆盖原始成果。
