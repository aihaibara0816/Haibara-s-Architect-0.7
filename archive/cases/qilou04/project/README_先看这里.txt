随机性
主街骨架与地块关系为本案编排，始终保留公共道路。
不同种子独立调整住宅宽深、退距、楼高、住户亮灯与细节；限制在各自地块范围内。
基准种子311148；对照种子311149。32栋住宅体量改变，23栋退距改变；两个版本均通过离线通行检查。
同种子45份NBT字节完全一致。不是逐块随机撒材质，也没有训练模型权重。
