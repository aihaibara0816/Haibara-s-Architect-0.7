## B. 历史实验与设计反馈（已有经验，不等于源码或交付物）

- 曾进行 7-Eleven、罗森等小商业建筑的 AI 复刻尝试；对应原始图片/生成结果/文件位置尚待核实。
- 广州塔、台北101、广州 IFC、周大福金融中心、中国尊等建筑有试验和反复优化经验。
- 典型负反馈：高楼“太矮太胖”、塔身被简化为直筒、收分/退台不明显、单一参考方向不足、材质与灯光缺失；应转化为可测的几何约束和质量检查。
- 用户重视不同方向参考图，核心轮廓优先于单张局部特写；复杂建筑可先建立可靠主体几何，再细化立面和夜间灯光。
- GAFAcraft 游戏环境的历史信息：Minecraft Java `1.21.1`、NeoForge `21.1.244`、Create `6.0.10`。**仅作预期兼容目标；需要读取当前整合包和服务器/测试客户端确认。**
