# HAF 细节经验与回归样例

本目录是工程经验记录，真实实现必须能指向代码消费者和生成结果。不是机器学习权重，也不代表通用建筑识别已经完成。

## 已落地

| 经验 | 实现 | 本轮检查 | 适用边界 |
|---|---|---|---|
| 稳定房间 ID 的随机灯光 | `hafusion/lighting.py`；深圳案例 `interior()`/`podium()` | 顺序无关、追加房间不扰动旧房间、同种子重放、不同种子变化 | 程序化办公室补全；不是实楼亮灯调查 |
| 保持玻璃、横带、窗后层的前后顺序 | `cases/shenzhen_press/src/build_case.py` 的 tower/interior | 原弧面和洞口保护、同机位近景及剖面 | 参数仍由本建筑证据手动确定 |
| 敞廊与缺失围护分开处理 | 案例 podium 后墙与端墙 | 后墙采样覆盖、保留入口开口 | 背面图不足，窗格样式估算 |
| 屋顶由体块和连接形成 | 案例 core/crown | 屋顶体量、左侧窗翼、顶部连接专用近景 | 屋顶深度和坡度未测绘 |
| 样本学表达，不照搬形态 | external schematic 研究记录 | 保留 HAF 左右手性、主弧面和入口 | 外部样本左右相反、灯光也有周期，未直接合并体素 |

## 下一建筑必须再次验证

选择非弧形办公塔和带大悬挑裙楼各一例，检验参数可迁移性、四周围护、窗后层次及灯光规则。深圳 V2 的认可不能替代新的建筑样例。把失败先写进具体 component_id 的反馈，再决定提取通用几何组件。
