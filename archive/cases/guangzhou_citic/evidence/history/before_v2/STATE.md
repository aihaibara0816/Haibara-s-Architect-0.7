# 广州中信广场 · HAF 0.4 案例

当前交付 V1_r04，2026-10-27。包含主办公塔楼、弧形商业裙楼、两翼公寓外观和直接入口广场。真实建筑复原结合缺资料部分的设计补全，不是纯原创建筑。

最终 NBT SHA256：33f931ad0a13d85b8f3f660117c47600dbfbda0086d1beb07d296b6fe5b383ce。

全场 92×188×98 格；统一 7/15 格每米。主塔地坪 Y3 到尖杆顶 182 格，尖杆已计入总高。官方总高390.2米；OSM平面及屋顶标签不是测绘资料。

四个示范标高：Y4 大厅、Y25 办公、Y81 项目协作、Y130 共享休息。其余为 L1 窗后片段，不能当80个正常可进入楼层。静态电梯核心未提供上下楼交通。

本案例适配器实际消费 HAF0.4 的 resolved module table。11个功能区/模块、16根视觉柱、14株场地树和737个发光方块；这些数字只属于本案。

现代示范层两格层间构造和齐平灯保留；高楼普通窗后50%暗/25%暖/25%冷为哈希目标分配，另有设备带/公共层例外，不代表实测开灯状态。真实冷暖光和光照覆盖未在游戏中验证。

保留 R01–R04 历史；R02验证失败不可覆盖。15项几何专项检查通过，HAF原工程62项回归通过；用户视觉评审、真实游戏导入/碰撞/灯光仍pending。三维查看器和两个报告已在桌面与手机宽度测试。

`params_used.json` 中早期 `run: V1_r01` 为未消费的初始标签；实际run以目录和manifest.run为准。`windows.json`为空，当前适配器以立面组件归属记录玻璃，尚未生成独立窗组ID，不可将manifest.window_count解释为没有玻璃窗。

下步优先：塔冠中缝/圆筒比例人工评审 → 原版游戏幕墙/夜景 → 若需可游玩写字楼，再单独设计垂直交通和实际可用楼层。局部返工应锁定其余已获认可部分；目前没有用户整栋验收记录。
