# 广州塔实际模型样本

`source.skp` 为用户上传原字节（原名“无标题.skp”），不是生成模型。`embedded_thumbnail.png` 来自原 SKP 内嵌缩略图，不是本轮新渲染。

`selection.json` 记录本轮显式塔体范围；`model_candidate.json` 为 BuildingSpec 0.2 的模型证据条目，status 仍为 candidate。真实读取输出位于 `output/model_canton_skp/`，多格式派生文件位于 `output/model_format_trials/`。

没有把这些三角网格体素化为 Minecraft，也未运行广州塔 SU V2。详见 `docs/MODEL_RESEARCH_0.3.md`。
