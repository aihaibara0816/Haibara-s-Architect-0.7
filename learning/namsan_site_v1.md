# 南山 V1：塔与山地场地接合

2026-10-23；HAF 0.2；基线 `cases/namsan_tower/runs/V1_r02`。

本轮验证了保存公开地形数据、复用地图平面、人工判断场地层次，再调用HAF方块状态、稳定灯光、NBT导出与独立回读的案例流程。并非自动模型训练，也没有新增独立安装的Skill。

保留的经验：

1. 先确定坐标与尺度，再划定公园范围。OSM主要供应平面位置；SRTM主要供应坡势；楼层图和照片供应细部层次。来源的适用范围不同，不把冲突高程取平均。
2. 地形和建筑不能只在最后拼接。大尺度DEM会包含树冠、屋顶及插值偏差，需要用有证据的台地替换局部高度，并在边缘过渡。
3. 设备环的面积不能全部铺满。南山塔使用外缘、辐条、竖撑和少量设备；观景舱才配置围护和功能楼板。
4. 室内楼板止于白色核心筒内缘。V1_r01 的服务楼板过大，覆写外墙造成虚假的灰条；r02已修复，增加专门检查。
5. 远景会掩盖近景相机穿入前景建筑的问题。首个八角亭相机被塔身遮挡并发生近裁切；只调整相机，保持NBT不变，失败样例留在validation。
6. 大场地的空中体积不等于实际方块预算。新SiteScene分别限制64M以内包围体积和2M以内占用方块；原Scene上限不动。项目实际使用40M包围体积/1.5M占用预算。
7. 夜景按固定外部灯、内部活动灯与装饰障碍灯分别处理。南山塔真实RGB投光尚不能由现有原版方块光照准确复现，本轮保留为缺口，不能把发光方块数量当还原度。

后续先核查游戏导入、台阶与通行、亭檐比例和塔身夜间投光表达。转入沙面类低矮西式建筑时，保留证据和校验链，新增柱廊/窗楣/檐口/屋顶/街巷比例研究，不复用南山的塔几何。
