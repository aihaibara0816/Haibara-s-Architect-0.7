# 广州新海关 · HAF V1

交付基线 `V1_r04`，案例版本 `0.1.3`，引擎 HAF `0.2.0`。
对象沿用用户已有资料包：花城大道83号的广州海关新业务技术综合楼。
本轮口述“天河北”与该地址存在出入；按既有资料继续，未把无回答记为用户确认。

纯图片解释路线，采用4张独立实景图及其细节裁剪；没有SU模型、相机恢复、正射拼接或自动分割。
原始资料包中103m、137m及数据库估算114m互有冲突。137格是本次试作包络，包含钟室、弧顶和细针；不能把它当成已测定的1:1总高度。

## 建筑与交付

- 主塔分段窗墙、浅色石材代理、真实凹窗、中央大拱窗。
- 小方钟室、离散化白色表盘、静态10:10、浅弧顶和细针。
- 一体低层基座、两个暗色玻璃盒、局部大拱窗、四圆柱入口、台阶与简化绿化。
- 楼板和局部窗后办公室；书架、工作台、植物、座椅与稳定房间灯光。
- 全景、细节、俯视和剖切，共22张最终NBT回读预览。含东南/西南/东北/西北四个45°日夜视角。
- 完整Sponge v3 `.schem`、Java结构`.nbt`、3个稀疏NBT分区、材料表、状态表和坐标偏移表。

方位标签是模型坐标：东 +X，北 −Z，主入口朝 +Z。没有测定真实地理北。
整体包围盒126×148×116，楼体试作包络137格；建筑尺寸与地景范围仍属图片估算。
四向日光统一使用显式 `sun_day=[0.6,0.9,0.8]`，不随相机转动。旧案例未设置此值时行为保持原样。

## 复现与局部修改

Python 3.12、numpy、Pillow；Linux离线渲染额外依赖可用的EGL/Mesa。

```bash
python3 tools/agent.py --case guangzhou_customs --run MY_NEW_RUN
python3 tools/render_building_case.py --case guangzhou_customs --run MY_NEW_RUN
python3 tools/package_building_case.py --case guangzhou_customs --run MY_NEW_RUN --name Guangzhou_Customs_Custom
python3 cases/guangzhou_customs/src/validate_case.py
PYTHONPATH=support/deps python3 -m unittest discover -s tests -v
```

不能使用已有run名覆盖历史。`params.json`控制钟冠、窗列、照明、基座构件等；本案例仍有显式坐标写在`src/build_case.py`。
它不是对任意尺寸无条件通用的生成器。变更整体宽深时需同时检查子体接口，不能只改一个数字后宣称已自动适配。
`validate_case.py`默认校验保存的交付基线与其重放，不是任意新建筑的还原度评分器。

原图、来源与采用状态在`research/image_manifest.json`；构件证据与消费者在`research/component_evidence.json`。
4轮内部原型、最终源码快照与参数另存，修改原因可查`history/revision_log.json`。
查看页可按构件/视角填写反馈并导出JSON；表单不会自动修改建筑。

## 材料与导入

首选用兼容Sponge v3的工具在空白场地试放完整`.schem`；它包含空气。
完整NBT及分区是稀疏结构，只列非空气，原有场地障碍不会由稀疏文件自动清理。
分区偏移取`module_offsets.csv`，每个分区原点为项目原点加其XYZ偏移，不旋转。
256KiB仅是分区压缩文件大小预算，不代表已经通过原版结构方块的尺寸或游戏兼容性验收。
`materials.csv`是最终实际方块数，`blockstates.csv`保留朝向、半砖上下半、玻璃连接等状态。

灰白石材采用石英/平滑砂岩等Minecraft材料表达，不主张现实材料是石英。
局部绿灰屋面用氧化铜代理颜色；未认定实际铜板或屋顶草坪。

## 已知边界

高度口径、平面精度、完整背面、基座拱窗所在的真实方位仍待核。
照片只能确认钟室相邻两面的表盘，另两面按构造连续性补全。
钟面数字缩为主刻度；入口“中国海关”字样未在该尺度强行生成伪文字。
无可信同楼夜景图；夜间为游戏灯光方案。暗/暖/冷使用50%/25%/25%概率，最终数量由材料与房间记录给出。
内饰和服务楼梯是解释性设计，未取得真实办公平面，也未验收整楼导航。
本地预览使用方块状态几何与近似光照，未加载Minecraft纹理；不是游戏截图。
文件读回、分区拼合和重复生成通过，不等于Minecraft导入、邻接更新、光照或用户还原度验收通过。

源码包保留相关第三方许可/来源，原始研究照片及字体不重复打包；查看页保留必要的有出处参考。
这里只记录建造规则和案例反馈，没有训练神经网络权重，也没有改写用户的网站。
