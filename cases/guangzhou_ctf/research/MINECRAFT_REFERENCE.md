# Minecraft 模板参考文件

这里的三个 JSON 是从 Minecraft Java 1.21.1 客户端资源提取的历史测试夹具，用来核对有限方块模型的尺寸。它们不是 HAF 原创建筑，也不随本项目代码统一更换许可证。

- `vanilla/template_wall_post.json` ← `assets/minecraft/models/block/template_wall_post.json`
- `vanilla/template_wall_side.json` ← `assets/minecraft/models/block/template_wall_side.json`
- `detail_study_v2/vanilla/template_anvil.json` ← `assets/minecraft/models/block/template_anvil.json`

两处相邻的 `source.json` 保留官方版本清单 URL、客户端 SHA-1、资源原路径和历史提取范围。源记录可能列出更多当时研究过的文件，不代表这些文件全部包含在当前公开副本中。
